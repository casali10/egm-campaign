# Run-Readiness Standard

A campaign document passes when a game master (GM) with no prior context can
run each session from the prep alone, and the arc holds together across
sessions. This standard applies to every campaign reviewer.

## What "enough" means

Prep is enough when each session has the eight-step minimum, about a sentence
or two per item:

1. **Character hooks:** each player character (PC) has a reason to care about
   this session.
2. **Strong start:** an opening scene that is written down and leads to a hook.
3. **Potential scenes:** a short list of scenes that may happen, in no fixed
   order.
4. **Secrets and clues:** about ten short facts the players could learn, each
   written without saying where or how it is found.
5. **Locations:** a few places, each with a few memorable details.
6. **NPCs:** the non-player characters likely to appear, each with a goal.
7. **Monsters and opposition:** who could fight or obstruct the party, as a
   short list.
8. **Rewards:** what the party could gain, tied to the characters where
   possible.

## Severity

- **Blocker:** a session cannot start or cannot reach its main hook from the
  prep alone, or a scene crosses a hard content boundary in the table record.
- **Major:** a missing or unusable essential from the list above; a secret the
  session depends on that has only one way to surface; a scene the whole
  session depends on; an arc contradiction a player would notice; a challenge
  that would likely end the campaign with no way out the table agreed to.
- **Nit:** wording, ordering, or over-prep. Over-prep (scripted dialogue,
  full stat blocks, fixed scene order) is a Nit unless it buries an essential,
  in which case it is Major.

## Table record

The document records the table: players and their characters, party level and
makeup, tone, difficulty target (for example heroic, gritty, or deadly), game
system if any, and content boundaries (for example lines that never appear and
veils that happen off-screen). Reviewers judge fit against this record, not
against their own taste. A missing table record is Major.

## Out of scope

- Rules accuracy for a specific game system, unless the table record names
  one and the prep relies on it.
- Writing quality beyond whether the GM can find and use the information.
